Sign in

This instance sends no reset email — sign-in passwords are set on the server: python -m app.cli set-password <username>

Ticked, the session cookie lives for this server's full session lifetime (7 days); unticked, it expires after 12 hours. Repeated failed sign-ins are rate-limited with a growing delay — a correct password always gets through.

Self-hosted · not Goodreads or Amazon · source on GitHub
